인노바드 조회 앱 아이콘용 런처 (GitHub Pages 에 올리는 파일)
1. index.html 의 EXEC_URL 에 구글 웹앱 주소(…/exec)를 넣는다.
2. 로고를 바꾸려면 같은 이름의 PNG 로 교체: icon-192.png(192×192), icon-512.png(512×512), icon-maskable-512.png(512×512, 가장자리 여백 넉넉히), apple-touch-icon.png(180×180), favicon.png(48×48)
3. 이 폴더 파일 전부를 공개 GitHub 저장소에 올리고 Settings → Pages 에서 main 브랜치로 게시.
※ 이 폴더에는 데이터·키가 없다. 웹앱 주소만으로는 아무것도 볼 수 없고 접속 키가 있어야 한다.
